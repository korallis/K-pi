# Context pack

The graph materializes context through `assembleAgentContext` at start/resume. Do not author a competing `context.md` truth source. Read the injected protected intent, required acceptance and task cursor; use `context_map` for feature ownership and structural file/symbol lookup, and `context_navigate` for configured native LSP symbols, definitions and references.

The manifest names raw artifacts and budget omissions. Retrieve those references on demand; do not substitute chat memory for decisions, failures or receipts. Missing semantic tooling reports unsupported, not regex-based semantics. Mandatory intent and criteria are never truncated: an overflow requires a larger context window or lower reserve. Acceptance changes require an authorized protected-intent revision.
