# Spec first

Research repository behavior and existing conventions before planning. Write `specs/<id>/requirements.md`, `design.md`, and `tasks.md` before implementation. Requirements include observable acceptance criteria, constraints, and non-goals. Design identifies existing extension points and risks. Tasks are ordered vertical slices with explicit checks and write bounds.

Do not implement production code. Do not invent evidence or mark narrative criteria executable.
